# Changelog

## 1.0.0 (2026-10-11)

First public release.
- Skill workflow covering intake, image analysis, library search, selection, storyboard, implementation, rendering, QA and delivery.
- motionprompts.dev integration over the REST API and hosted MCP, with a 7-day cache, offline fallback, previews, prompt/source fetch and credits.
- Image inspection and background cutout.
- A deterministic timeline runtime and a Playwright + FFmpeg renderer with ffprobe verification and QA contact sheets.
- An original procedural music generator, with audio muxed into the render.
- Packaged as a Claude Code plugin with a marketplace manifest.
- Three worked examples.
