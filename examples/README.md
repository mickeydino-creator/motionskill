# Examples

Each folder holds a real run of the skill: the generated `index.html` (the film), `CREDITS.md` (the library components used and how), verified MP4 renders, and a contact sheet taken from the encoded video.

- [**AURELIA: chrome perfume reveal**](aurelia-chrome-perfume/). Luxury and futuristic, a WebGL liquid-chrome backdrop with a dramatic light reveal. 16:9 + 9:16, 10 s. Synthetic test brand.
  ![](aurelia-chrome-perfume/renders/contact-sheet-16x9.jpg)
- [**Spotify: kinetic type, 9:16**](spotify-kinetic-9x16/). Energetic stretch type and marquees on a 120 BPM grid, 10 s.
- [**Spotify: kinetic type with music, 16:9**](spotify-kinetic-16x9-music/). 15 s, cut to an original synthesised track.
  ![](spotify-kinetic-16x9-music/renders/contact-sheet.jpg)

The Spotify pieces are **unofficial portfolio spec work**. They are not affiliated with or endorsed by Spotify, and the Spotify logo files are not included.
